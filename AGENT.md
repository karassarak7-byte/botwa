# Bot WA (bot-wa)
- Entry: index.js (ESM, "type": "module"). Start: node index.js (MAIN_FILE=index.js). Panel image Node 25, port 10775 (PORT/SERVER_PORT), listen 0.0.0.0.
- Login: QR di terminal dan halaman http://IP:10775/ (/qr.png). Session di folder auth.
- Install ulang: npm install, lalu node patch-fps.mjs (wajib, mengatur batas stiker video).
- File:
  - index.js: server HTTP, start() dengan makeWASocket (autoFollowChannel false), handleMessage (switch cmd), explainError, cropSquareVideo, sendSoundSticker, bratSticker, measureInk, wrapBrat, xmlEsc, addStickerExif, handleBrat, handleSticker, handleRangkum, buildMenu, handleClaim, handleTebak, handleJawab, handleClue, handleMenyerah, handleSetEnergy, handleCekUser.
  - Konstanta di index.js: STICKER_CUT_SECONDS 7, STICKER_MAX_SECONDS 10, BRAT_COST 2, BRAT_MAX_CHARS 100, BRAT_SY 1.3, BRAT_WATERMARK 'bot by nuzzelll'. Baris pertama set FONTCONFIG_FILE ke fonts/fonts.conf.
  - database.js: users.json, spendEnergy, refundEnergy, claimEnergy, playSpin, getUser, findUser, setEnergy, addEnergy, markGreeted, countCall, antrean tulis atomik.
  - ai.js: groupChatCache, recordGroupMessage, getRecentMessages, askAI (Gemini gemini-2.5-flash, REST). Memuat .env sendiri.
  - werewolf.js: initWerewolf, handleWW, handleVote, handleWWDM, buildRoles, newGame, armLobbyTimer, onLobbyTimeout, startGame, endGame. LOBBY_MS, LOBBY_JOIN_MS, NIGHT_MS, DAY_MS, VOTE_MS, REWARD=20, MIN_PLAYERS=4.
  - tebakkata.js: WORDS (100 kata, 3 clue per kata), startGame, takeClue, guess, giveUp, prizeFor, formatClues. BASE_PRIZE=20, CLUE_PENALTY=0.2, MAX_CLUES=3, sesi 5 menit di memori.
  - patch-fps.mjs: patch node_modules/@xbibzlibrary/whatsbibz/lib/Utils/sound-sticker.js.
  - fonts/: LiberationSans-Regular.ttf, LiberationSans-Bold.ttf (SIL OFL), fonts.conf.
- Paket: @xbibzlibrary/whatsbibz 2.1.0 (fork Baileys, helper sound sticker di lib/Utils/sound-sticker.js), qrcode, pino (silent), sharp 0.32.6, ffmpeg 5.1.9 di /usr/bin.
- Perintah (prefix !):
  - !menu/!help, !ping, !energi/!cek, !claim (+15 tiap 1 jam), !spin, !tebak, !jawab, !clue, !menyerah.
  - !sticker/!s: 3 energi, refund jika gagal. Video dipotong 7 detik, input maks 10 detik. Dikirim lewat sendSoundSticker (relayMessage tanpa type khusus, sama seperti sendVideoAsSoundSticker library yang diuji live; nama pack/publisher "bot by nuzzelll" lewat EXIF).
  - !brat <teks>: 2 energi, maks 100 karakter, teks dari balasan juga boleh. Tiap baris diregangkan ke lebar penuh, font Liberation Sans, latar putih, kualitas webp 50, grid 40.
  - !rangkum/!tldr [jumlah]: 5 energi, grup saja, default 30, min 5, maks 30, refund jika gagal.
  - !werewolf / !ww create/join/leave/start/status/stop, !vote, aksi malam via DM. Hadiah +20. Peran seer, doctor, vigilante, netral (jester, fool, serial) tidak boleh ganda. Netral mulai 6 pemain. Jumlah werewolf = floor(n/4), 1 Alpha mulai 8 pemain.
- Dihapus atas permintaan, jangan dikembalikan kecuali diminta: !ai/!tanya, !nobg, !hitam, !hd, !bratwhite.
- Stiker WhatsApp maks 500 KiB. Jangan naikkan batas ini.
- Energi: awal 30, maks 150, cooldown 2 detik per pengguna, batas input 2 MB.
- Pengendali: 6289692853559 (kebal jeda dan biaya stiker). Perintah !setenergi <nomor> <0-150>, !cekuser <nomor>.
- Chat pribadi: pesan fromMe hanya diproses di self-chat. Sapaan otomatis untuk chat pribadi baru dan member baru grup.
- Panggilan ke bot: panggilan pertama dibalas peringatan, berikutnya diblokir (rejectCall, updateBlockStatus).
- Repo GitHub karassarak7-byte/botwa, branch main, AI auto backup aktif.
